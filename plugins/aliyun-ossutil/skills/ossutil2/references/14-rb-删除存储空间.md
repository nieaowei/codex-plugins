rb命令用于删除存储空间。

## 注意事项

要删除Bucket，您必须具有`oss:DeleteBucket`权限。

## **命令格式**

```
ossutil rb oss://bucket [flags]
```

| **参数** | **说明** |
| --- | --- |
| \\-f, --force | 删除存储空间前，删除所有的对象。 |

**说明**

关于支持的全局命令行选项，请参见[支持的全局命令行选项](https://help.aliyun.com/zh/oss/command-line-options#65785a4884d85)。

## **使用示例**

-   删除空的存储空间examplebucket。
    
    ```
    ossutil rb oss://examplebucket
    ```
    
-   使用--force参数删除非空的存储空间examplebucket。
    
    ```
    ossutil rb oss://examplebucket --force
    ```
